## 🧭 How we build

- **One default branch: `main`** — all repos, no exceptions.
- **Branches:** `feature|bugfix|chore/<JIRA-KEY>-short-description`
- **PRs:** small and focused — one ticket, one PR, squash merge. Jira key in the title, assign yourself, CI must be green.
- **CI/CD:** GitHub Actions (starter templates in this repo under `workflow-templates/`).
- **Infrastructure as code:** Terraform + Atmos on AWS and OCI.
